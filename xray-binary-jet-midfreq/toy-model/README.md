# Toy model: jet of an X-ray binary: time-variable, precessing, double-sided (SS 433-like microquasar)

The model is **generated by code**, not read from a file: `gaussian_array()` and `get_toy_model_frame()` in Section 2 of the notebook and in `script/binary_jet_VLBI_campaign_full.py`. To produce the model on its own, run **`script/toy_model_xray_binary_jet.py`**: it writes the true sky of every day (FITS and PNG), a GIF of the campaign, a montage, the light curve and, with `--track-day`, the evolution of the source within one 6-h track. The files here are a snapshot for reference.

| File | Content |
|---|---|
| `truth_day22.fits` | the true sky on the imaging day (day 22), 256 × 256 pixels over 60 mas |
| `ground_truth_montage.png` | the true sky on 8 days of the 43-day campaign |

| Parameter (notebook Section 0.1) | Value | Meaning |
|---|---|---|
| `RA_SOURCE`, `DEC_SOURCE` | 19.19 h, +4.98° | position |
| `N_BLOBS` | 20 | ejecta pairs (two-sided) |
| `SPACING_FRAMES` | 52 | model frames between ejections |
| `PRECESSION_PERIOD` | 800 | model frames per precession cycle |
| `OPENING_ANGLE` | 0.55 | opening of the precession cone |
| `INCLINATION` | 0.0 | inclination of the precession axis |
| `VELOCITY_FACTOR`, `DECAY_UAS` | 0.4, 100 (× scale) | blob speed per frame, fading length |
| `BLOB_CORE_UAS`, `BLOB_HALO_UAS` | 6, 14 (× scale) | blob core and halo sizes |
| `FRAMES_PER_DAY`, `TIME_FACTOR` | 4.76, 1.0 | evolution per observing day, time compression within a track |
| `N_DAYS` | 43 | campaign length |

The total flux varies between 1.8 and 5.6 Jy over the campaign (4.0 Jy on day 22).
